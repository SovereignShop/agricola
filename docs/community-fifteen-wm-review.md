# Original WM batch fifteen

All ten final English card prints were visually checked against the actual card title, WM number, costs, prerequisite icons and full rules text. The local artwork manifest records each PlayAgricola source URL and SHA256. Cross-check: https://www.reedstonefood.com/agricola/compendium . Almshouse's actual print and catalogue cost **one wood and one reed**; the compendium's two/two transcription is not used.

| Prepared test table | Interaction and rule verification |
|---|---|
| Borrower | Pictured three-food repayment, one eligible begging card at a time. Borrower and family-feeding origins tracked separately from other penalties. |
| Chemist | Actual action board highlights different revealed building-resource accumulation spaces. One clay paid and added to that pile, two food received. Includes five-player Reed/Stone/Wood action; newly taken clay is usable. |
| Family Planner | Future round card selection with family figures. Reserved supply pieces unavailable for earlier growth. Arrival releases the token and offers native newborn growth, with room checks and applicable growth permissions. |
| Lady in Waiting | Stage-one reservation shown on round twelve. Arrival offers two-food exchange for an adult who can act immediately, with no room requirement. Explicitly not a Family Growth action. |
| Storehouse Minder | Distinct pictured resources deposited; up to two present types increased at Harvest start. Once per round choose a pictured type to collect its whole stock. Stored resources contribute to craft-improvement endgame bonuses. |
| Almshouse | Native feeding creates eligible penalties before the optional discard. Borrower and other card penalties cannot be discarded. |
| Cash Crop | Native card-field sowing; normal Harvest Field phase produces a permanent point instead of the harvested crop. Outside-harvest removal supplies the crop normally. Printed bonus-point symbol is registered. |
| Fish Pond | Direct unused-farm-space clay-marker placement, then pictured Fishing-food quantity to stored scoring food. Card bonuses excluded; stored food never spendable. |
| Rotherham Plow | Shared direct farm plow flow with nonadjacent second-field filtering, including diagonal separation. Ordinary field connectivity still enforced; unlimited uses. |
| Slapdash Renovation | Optional pictured return of the exact source renovation worker, freeing that action space and restoring one later action. |

Native tests cover resolution, optional decline, source restrictions, storage, reservations, growth/arrival distinctions, persistence and recording replay. Browser checks exercise all ten in web, desktop Discord and mobile Discord, including no-dropdown assertions, direct farm/board choices, responsive dialog widths and visible resulting pieces/resources.
